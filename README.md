# MROKU - DJ & Wodzirej

Gotowa strona statyczna pod GitHub Pages.

## Publikacja
1. Utwórz nowe publiczne repozytorium na GitHubie.
2. Wgraj `index.html`.
3. GitHub → Settings → Pages → Deploy from branch → `main` / root.
4. Po publikacji GitHub poda adres strony.

## Kalendarz
Kalendarz działa po stronie przeglądarki przez `localStorage`. Domyślne hasło panelu to `MROKU2026`. Zmień wartość `PASS` w `index.html` przed publikacją.

Ważne: ponieważ GitHub Pages jest hostingiem statycznym, wpisy kalendarza nie są wspólną bazą online. Zapisane na komputerze wydarzenia nie pojawią się automatycznie na telefonie. Do wspólnej synchronizacji między urządzeniami potrzebny jest backend/baza danych.
